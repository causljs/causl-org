Module src

Public-surface barrel for @causl/core.

Re-exports the canonical seven-method API — createCausl, graph.input, graph.derived, graph.commit, graph.read, graph.subscribe, graph.explain — together with the second-tier extensions justified individually on the Graph interface (subscribeCommits, commitLog, exportModel, simulate, snapshot, hydrate, readAt, snapshotAt, now), the structured error classes for the race-class catalogue, and the CauslModel IR plus its JSON Schema document — the bridge from the TypeScript engine to the Rust causl-check bounded model checker.

Consumers should rely on this barrel; deep imports into individual modules are not part of the supported surface.

A wasm-first public surface

@causl/core is driven by the Rust→WASM core (SPEC §18A.13). As of the CUT (epic #31 / issue #34) the public surface no longer lets an adopter pick the pure-TS engine directly — createCauslTs is not exported from this barrel. The two supported public entry points are:

  • createCausl(options) — the default factory. Per the #33 FLIP it PREFERS the real wasm engine WHEN @causl/core/wasm has been preloaded for the default bridge, and otherwise builds a working sync Graph on the internal TS floor (kept non-breaking for sync callers that never import/preload the wasm subpath).
  • createCauslWasm(options) — the async wasm factory, exported from the @causl/core/wasm subpath (kept out of the main bundle). This is the SPEC §18A backend contract: the same seven-method spine, driven by the Rust→WASM core through a thin marshalling bridge.

Reach the wasm subpath with import { loadWasmBackend } from '@causl/core/wasm' and pass backend: await loadWasmBackend() to createCausl(options), or call preloadCauslWasm() so a bare createCausl() routes through wasm. The pure-TS engine still exists INTERNALLY (the wasm path wraps it as its structural / handle / dependency layer) but is no longer a public engine choice. See the @causl/core/wasm module for loadWasmBackend, BackendEngine, WasmBackendOptions, and the Bridge FFI surface.
